1. Create a class called Song in your preferred OOP language with private properties title and artist. Add public getter and setter methods to access and modify these properties, then create an object and update its title.

#include <iostream>
using namespace std;

class Song 
{
private:
    string title;
    string artist;

public:
    string getTitle() 
    {
        return title;
    }

    void setTitle(string newTitle) 
    {
        title = newTitle;
    }

    string getArtist() 
    {
        return artist;
    }

    void setArtist(string newArtist) 
    {
        artist = newArtist;
    }
};

int main() 
{
    Song song;

    song.setTitle("Lover");
    song.setArtist("Taylor Swift");

    song.setTitle("Daylight");

    cout << "Updated title: " << song.getTitle() << endl;

    return 0;
}

3.Imagine a Flipkart-like app: create an abstract class Product with an abstract method upload(). Then, create two subclasses, Electronics and Clothing, that each implement the upload() method to print a different upload message.

#include <iostream>
using namespace std;

class Product 
{
public:
    virtual void upload() = 0;
};

class Electronics : public Product 
{
public:
    void upload() override 
    {
        cout << "Uploading Electronics product to Flipkart" << endl;
    }
};

class Clothing : public Product 
{
public:
    void upload() override 
    {
        cout << "Uploading Clothing product to Flipkart" << endl;
    }
};

int main() 
{
    Electronics e;
    Clothing c;

    e.upload();
    c.upload();

    return 0;
}

5. Explain in your own words the difference between encapsulation and abstraction, using examples from any social media app you use daily (like Instagram or WhatsApp).

Encapsulation
Encapsulation means keeping things together and protected.

For example, in WhatsApp, your message, sender name, and message time are handled together by the app. You cannot directly change WhatsApp's internal message data. You use the options WhatsApp gives you.

Simple meaning: “Keep data safe and control it.”

Abstraction
Abstraction means hiding complicated things and showing only what you need.

For example, when you press the Send button, you don't need to know how WhatsApp sends the message through the internet. WhatsApp does all the complicated work for you.

Simple meaning: “Hide the difficult work and show the easy part.”

One-line difference
Encapsulation = Protect the data.
Abstraction = Hide the complexity.
