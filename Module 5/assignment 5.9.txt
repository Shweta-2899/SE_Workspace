sql
```
START TRANSACTION;

INSERT INTO Cart (CartID, UserID, ProductID, ProductName, Quantity, Price)
VALUES (1, 101, 201, 'Wireless Mouse', 1, 599.00);

SAVEPOINT product_added;

INSERT INTO Cart (CartID, UserID, ProductID, ProductName, Quantity, Price)
VALUES (2, 101, 202, 'Keyboard', 1, 999.00);

ROLLBACK TO SAVEPOINT product_added;

SELECT *
```

4.Write a trigger on a Wallet table that automatically deducts the purchase amount from the user's balance whenever a new transaction is inserted, similar to how Paytm updates wallet balance after a payment.

sql
```
CREATE TRIGGER deduct_wallet_balance
AFTER INSERT ON Transactions
FOR EACH ROW
BEGIN
    UPDATE Wallet
    SET Balance = Balance - NEW.Amount
    WHERE UserID = NEW.UserID;
END;
```

1. Buggy trigger example
The following trigger incorrectly adds an expense amount to the user's balance instead of deducting it.

sql
CREATE TRIGGER update_balance_after_expense
AFTER INSERT ON Transactions
FOR EACH ROW
BEGIN
    UPDATE Wallet
    SET Balance = Balance + NEW.Amount
    WHERE UserID = NEW.UserID;
END;
2. SQL test scenario
sql
CREATE TABLE Wallet (
    UserID INT PRIMARY KEY,
    Balance DECIMAL(10,2)
);

CREATE TABLE Transactions (
    TransactionID INT PRIMARY KEY,
    UserID INT,
    Amount DECIMAL(10,2),
    TransactionType VARCHAR(20)
);

INSERT INTO Wallet VALUES (101, 5000.00);

INSERT INTO Transactions
VALUES (1, 101, 500.00, 'Expense');

SELECT * FROM Wallet;
Expected balance: 4500.00

Actual balance with the buggy trigger: 5500.00

The trigger adds ₹500 instead of subtracting it, causing an incorrect wallet balance.

3. Corrected trigger code
sql
DROP TRIGGER IF EXISTS update_balance_after_expense;

DELIMITER //

CREATE TRIGGER update_balance_after_expense
AFTER INSERT ON Transactions
FOR EACH ROW
BEGIN
    IF NEW.TransactionType = 'Expense' THEN
        UPDATE Wallet
        SET Balance = Balance - NEW.Amount
        WHERE UserID = NEW.UserID;
    END IF;
END //

DELIMITER ;

5. Explanation
Fixed the calculation: Changed Balance + NEW.Amount to Balance - NEW.Amount.

Added a condition: The trigger deducts money only when TransactionType = 'Expense'.

Prevented incorrect updates: Income transactions will not be deducted by this trigger.
