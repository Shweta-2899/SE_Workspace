1.Create an HTML file that uses semantic tags to build a simple blog post layout with <header> for the blog title, <nav> for navigation links (Home, Explore, About), <article> for the main post content, and <footer> for copyright information.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Simple Blog</title>
</head>
<body>

    <header>
        <h1>My Simple Blog</h1>
    </header>

    <nav>
        <a href="#">Home</a>
        <a href="#">Explore</a>
        <a href="#">About</a>
    </nav>

    <article>
        <h2>Welcome to My Blog</h2>
        <p>
            This is a simple blog post created using semantic HTML tags.
            Semantic elements make the structure of a webpage clearer and
            more meaningful.
        </p>

        <p>
            Here, the article contains the main content, while the header,
            navigation, and footer provide the surrounding page structure.
        </p>
    </article>

    <footer>
        <p>&copy; 2026 My Simple Blog. All rights reserved.</p>
    </footer>

</body>
</html>
